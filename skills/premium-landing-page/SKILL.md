# Premium Landing Page

## Workflow

1. Preserve the product message and content hierarchy unless the user asks for copy changes.
2. Establish a clear visual system: brand mark, color tokens, background atmosphere, section rhythm, cards, diagrams, and CTA emphasis.
3. Use repo-native visuals first: CSS gradients, SVG, React components, motion, and structured diagrams. Prefer raster images only when the user explicitly asks for generated bitmap assets.
4. Keep the result enterprise-grade: dramatic but controlled, high contrast, generous spacing, serious typography, crisp borders, premium shadows, and accessible responsive layouts.
5. Add visual metaphors that explain the product: flows, nodes, ledgers, gates, security shields, integration maps, and architecture layers.
6. Validate with `npm run build` after implementation.

## Design Rules

- Do not create generic SaaS templates.
- Use layered ambient backgrounds, but keep content readability high.
- Avoid toy-like color overload. Use one primary signal color, one accent color, deep ink surfaces, and restrained glow.
- Use motion sparingly for atmosphere and comprehension, not distraction.
- Every decorative visual should reinforce the product story.
